How to use a course

01

Install LearnCad

Install the FreeCAD addon from the download page. FreeCAD 1.1 or newer is required.

02

Open Courses

In the LearnCad panel, open the three-dot menu and choose Courses, or use LearnCad > Import Course....

03

Import and build

Choose the downloaded .learncad file. Pick a lesson and follow the highlighted control. Progress is saved locally.

Publish your own course

V0 is open and free. Package a course with the course tool, then submit it as a pull request. A maintainer reviews the manifest, assets, and lesson text before it appears here.

Start with docs/COURSES.md in the repository. Courses must be data-only, carry a license, and include no executable files.
