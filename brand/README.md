# LearnCad brand assets

LearnCad is a CAD coaching app. The logo combines a drafting compass with a
learning-by-building idea. It is intentionally simple enough to read at toolbar
and favicon sizes.

## Files

Vector:

- `logo-mark.svg` - square mark for the app, workbench, favicon, avatar.
- `logo-horizontal.svg` - primary lockup for dark backgrounds.
- `logo-horizontal-light.svg` - lockup for light backgrounds.
- `logo-horizontal-mono.svg` - single-color white lockup for overlays.
- `logo-stacked.svg` - square-ish lockup for covers and splash screens.

Raster:

- `png/logo-mark.png` - 512 px transparent mark.
- `png/logo-horizontal.png` - transparent dark-background lockup.
- `png/logo-horizontal-light.png` - transparent light-background lockup.
- `png/logo-horizontal-mono.png` - transparent white lockup.
- `png/logo-stacked.png` - transparent stacked lockup.
- `png/logo-preview-dark.png` - usage preview on black.
- `png/logo-preview-light.png` - usage preview on light gray.
- `png/learncad.ico` - Windows icon (16-256 px).

## Colors

| Token | Hex | Use |
| --- | --- | --- |
| LearnCad orange | `#ff7a18` | primary accent, "Cad" |
| Warm amber | `#ffb347` | secondary accent, compass arc |
| Ink | `#080808` | mark background, dark UI |
| Paper | `#f5f5f5` | wordmark on dark |
| Muted | `#9bb0c6` | tagline on dark |

## Typography

The wordmark uses Segoe UI Bold with tight tracking. The tagline uses Segoe UI
Semilight with wide tracking. PNG exports are provided so the lockup is identical
where Segoe UI is unavailable.

## Usage

- Use `logo-horizontal.svg` on the dark site and app surfaces.
- Use `logo-horizontal-light.svg` on white or light gray.
- Use `logo-mark.svg` for the app icon, favicon, and small avatars.
- Use `logo-horizontal-mono.svg` when the background is a photo or a busy render.
- Keep clear space around the mark equal to at least a quarter of its width.
- Do not stretch, rotate, recolor, add shadows, or place the dark lockup on a
  mid-tone background without a container.

## Naming

The product is **LearnCad**. The logo and name identify the LearnCad app; the
modeling engine is an internal component.
